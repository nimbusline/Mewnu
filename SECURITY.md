# Security policy

Mewnu reads private calendar information. Please report a suspected security or privacy issue privately so it can be investigated before details become public.

## Supported versions

Security fixes target the [latest stable published release](https://github.com/nimbusline/Mewnu/releases/latest). Reports affecting the current `main` branch are also welcome. Older releases are not maintained; upgrade to the latest stable release to receive fixes.

## Reporting

Report suspected security or privacy issues privately to [hello@gerdemann.me](mailto:hello@gerdemann.me). If private vulnerability reporting is enabled for the repository, you may also use **Security → Report a vulnerability** on GitHub. Include the affected version or commit, macOS version, steps to reproduce, and the possible impact. Use synthetic calendar data in examples; do not send real calendar content, account names, passwords, or signing credentials.

Do not post exploit details in a public issue or pull request.

The maintainers will acknowledge reports as soon as practical, assess the impact, and coordinate a fix and disclosure with the reporter.
