# Security policy

Mewnu reads private calendar information. Please report a suspected security or privacy issue privately so it can be investigated before details become public.

## Supported versions

There is no published release yet. Reports affecting the current `main` branch are welcome. After the first release, this section will identify supported release versions.

## Reporting

Report suspected security or privacy issues privately to [hello@gerdemann.me](mailto:hello@gerdemann.me). Once the repository is public and private vulnerability reporting is enabled, you may also use **Security → Report a vulnerability** on GitHub. Include the affected version or commit, macOS version, steps to reproduce, and the possible impact. Use synthetic calendar data in examples; do not send real calendar content, account names, passwords, or signing credentials.

Do not post exploit details in a public issue or pull request.

The maintainers will acknowledge reports as soon as practical, assess the impact, and coordinate a fix and disclosure with the reporter.
