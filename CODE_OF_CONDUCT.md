# Code of Conduct

Mewnu welcomes thoughtful contributions and respectful discussion in issues, pull requests, reviews, and other project spaces.

## Expected behavior

- Be considerate and specific when giving feedback.
- Assume good intent while remaining open to correction.
- Respect different experience levels, backgrounds, and accessibility needs.
- Protect other people's privacy. Use synthetic calendar data in public examples.

Harassment, discriminatory language, personal attacks, threats, unwanted sexual attention, and publishing another person's private information are not acceptable.

## Enforcement

Maintainers may edit or remove comments, close discussions or pull requests, limit participation, or block accounts when behavior violates this policy. Decisions should consider the impact and severity of the behavior.

For abusive content on GitHub, use GitHub's **Report content** option. For a concern that should be handled by the project maintainers, use the **Private contact request** issue template without personal details; a maintainer will arrange a private channel. Do not post a confidential report in a public issue.
